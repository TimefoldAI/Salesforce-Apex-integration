# Contributing

Thank you for the interest. We are not accepting code contributions to this repository at this
time.

Only collaborators can open pull requests, so pull requests from forks are not possible.
This is not about the quality of the work. This integration describes how Salesforce Field
Service data maps to the Timefold models, so we keep authorship of it with the team that builds
those models.

## What you can do instead

- **Report a bug.** [Open an issue](https://github.com/TimefoldAI/Salesforce-Apex-integration/issues).
  Tell us what you ran, what you expected, and what happened. Please leave out your API key, your
  tenant ID, your Salesforce org details, and any customer data.
- **Ask for a change.** Open an issue and describe the problem you want to solve. We would rather
  hear the problem than receive the solution.
- **Ask a question about the Timefold models.** Use the
  [Timefold documentation](https://docs.timefold.ai) or contact Timefold support.
- **Build your own.** The code, the scripts, and the documentation are under the
  [Apache License 2.0](./LICENSE). Copy them, change them, and keep the result in your own
  repository. You owe us nothing beyond the license terms.

## For Timefold employees

Work in a branch of this repository and open a pull request against `main`. You need write
access to the repository for this.
