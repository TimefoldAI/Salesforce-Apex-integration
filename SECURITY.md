# Security policy

Please do not report a security problem in a public issue.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/TimefoldAI/Salesforce-Apex-integration/security/advisories/new).
Tell us which class, script, or metadata file is affected, and how to reproduce the problem.
Please leave out your API key, your tenant ID, your Salesforce org details, and any customer data.

For a security problem in the Timefold platform or the Timefold models, contact Timefold support.
